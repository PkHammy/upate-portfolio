## 🛠️ Run locally

With Node.js 22.12+ installed:

```sh
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

```sh
npm run build     # Production build
npm run preview   # Preview the build
npm run lint      # ESLint checks
```

The repository also includes a Bun lockfile and declares Bun 1.2.0 as its package manager. Production builds use Nitro's Vercel preset.
